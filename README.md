[과제 - 09] 모든 정점 쌍의 최단경로 탐색 - 요약 및 구현 방향

1. 과제 개요 (Task Summary)
- 목표: 정점 10개, 간선 20개를 가진 무방향 가중치 그래프를 무작위로 생성하고, 모든 서로 다른 두 정점 쌍(총 45쌍)에 대해 최단경로와 최단거리를 계산하여 출력하는 프로그램 작성.
- 사용 언어: C언어

2. 주요 요구사항 및 조건 (Requirements)
- 그래프 스펙:
  * 정점의 수: 10개 (번호: 0 ~ 9)
  * 간선의 수: 20개
  * 가중치: 1 ~ 100 사이의 양의 정수 (무작위 부여)
- 제약 사항:
  * 자기 자신을 연결하는 간선(Self-loop) 허용 안 함.
  * 동일한 두 정점 사이의 중복 간선(Multiple edges) 허용 안 함.
  * 생성된 그래프는 반드시 모든 정점 사이에 경로가 존재하는 연결 그래프(Connected Graph)여야 함.
- 출력 내용:
  * 무작위 생성된 20개의 간선과 가중치 목록 출력.
  * u < v 조건을 만족하는 총 45개의 정점 쌍에 대해 출발/도착 정점, 최단경로(Path), 최단거리(Distance) 출력.

3. 단계별 구현 방향 (Implementation Guide)

① 1단계: 무작위 그래프 생성 및 연결성 검증
- 데이터 구조: 인접 행렬(Adjacency Matrix) `adj[10][10]` 활용.
- 간선 생성: `rand()` 함수로 무작위 정점 u, v (u != v)를 선택하고, 이미 연결되어 있지 않다면 1~100 사이의 가중치를 부여하여 총 20개의 간선 생성.
- 연결성 확인 (DFS/BFS):
  * 20개의 간선이 모두 생성된 후 DFS/BFS를 이용해 모든 정점이 서로 도달 가능한지 확인.
  * 고립된 정점이 있어 연결 그래프가 아니라면 조건을 만족할 때까지 그래프를 다시 생성 (`while` 루프).

② 2단계: 최단경로 알고리즘 적용 및 경로 복원
- 알고리즘: 모든 정점 쌍의 최단경로를 구하기 위해 Floyd-Warshall 알고리즘 적용.
- 경로 복원 (`next_node` 배열):
  * 최단 거리뿐만 아니라 실제 경로(예: 0 -> 3 -> 6 -> 1)를 출력하기 위해 `next_node[i][j]` 배열을 함께 운영.
  * Floyd-Warshall 갱신 과정에서 `next_node[i][j] = next_node[i][k]`로 업데이트하여 추후 역추적 가능하도록 구현.

③ 3단계: 45개 정점 쌍 결과 출력
- u는 0부터 9, v는 u + 1부터 9까지 반복하는 2중 포문을 사용하여 순서가 바뀐 중복 쌍(예: (0, 1)과 (1, 0))을 배제하고 정확히 45쌍만 출력.
- 각 쌍마다 `next_node`를 추적하여 Path를 그리고, 최종 Distance를 출력.
